# Messier Calendar

An interactive year-long chart of when each of the 110 Messier objects is highest in the night sky, with twilight,
moonlight, a location picker, per-object visibility and a view of the sky overhead.

Live at https://cosmic-obs.github.io/messier/

The pages are `index.html` (built from `web/poster.html`) and `sky.html`, published from the messier-calendar project.
